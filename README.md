## ☣ What is DEADBYTE?

**DEADBYTE** is a local Python research terminal that brings historical records, library catalogs, public web archives, heritage media, newspaper records and historic storm-event data into a single Reaper Deck interface. Its private **DEAD VAULT** stores local research sessions without uploading them to the GitHub repository.

The project is designed for source-transparent research: actual returned records, original source links, honest provider errors and clear distinctions between **event dates**, **archive capture dates** and **media upload dates**.

## ☠ 16-position REAPER DECK

| Switch | Module | Research role |
|:--:|---|---|
| 01 | Internet Archive | Books, media, documents and archive metadata |
| 02 | Open Library | Authors, books and editions |
| 03 | Library of Congress | Public historical collections |
| 04 | Wikisource | Digitized public-domain texts |
| 05 | Project Gutenberg / Gutendex | Historical ebook discovery |
| 06 | Historical Newspapers | LOC plus Internet Archive fallback |
| 07 | Wayback Machine | Historical URL capture indexes |
| 08 | Common Crawl | Public crawl discovery |
| 09 | Archive-It | Institutional archived webpages |
| 10 | Wikimedia Commons | Keyless historical images and file metadata |
| 11 | Multi-source Fusion | Cross-source keyword research |
| 12 | DEAD VAULT | Local research sessions and retrieval |
| 13 | Provider Field Notes | Sources, coverage and accuracy cautions |
| 14 | DEAD ARCHIVES | Sentence-based research and NOAA historical storm intelligence |
| 15 | Shadow Slot | Reserved for future development |
| 16 | Reserved Bay | Reserved for future development |

Switches **15–16 are placeholders**, not active research engines. Online sources vary in availability and completeness.

## ⚡ Historical geo-storm intelligence

The NOAA research module supports historical U.S. storm-event discovery with year-scoped datasets, chronological event reading, monthly distributions, state and storm-type filtering, and per-event evidence details. Event counts describe **database rows**, not necessarily unique storms. Early NOAA periods have narrower recorded coverage.

## 🟣 Local DEAD VAULT

Research sessions live on the user's own machine, outside this GitHub source repository. A vault index helps locate and revisit previous searches. **Private session data, local backups and machine-specific configuration are intentionally excluded from this project.**

## 🛠 Install on Linux

**Copy all four commands** for a fresh Linux installation. The repository is currently private, so cloning requires GitHub account access.

```bash
git clone https://github.com/Hellfire13666/DEADBYTE-DIGITAL-AFTERLIFE.git
cd DEADBYTE-DIGITAL-AFTERLIFE
sh install.sh
deadbyte
```

Requires Linux, Python 3, Git and the POSIX `install` utility. The installer **refuses to overwrite** an existing DEADBYTE installation or private research vault. The package passed local syntax and disposable-home launch checks, but is not yet certified across every Linux distribution. See [INSTALL.md](INSTALL.md) for troubleshooting.
