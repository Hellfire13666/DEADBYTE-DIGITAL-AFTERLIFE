20 original, copy-ready local research and vault workflows for the existing deadbyte one-word launcher. Electric-blue, violet, magenta and wicked green. Every automated shell command is visible before you copy it. Nothing here remotely scans private targets or modifies your approved DEADBYTE installation.

HOW TO USE: Click COPY RECIPE, paste into your Linux terminal, then for research recipes enter the shown switch and keyword inside DEADBYTE. The terminal prints research results and tee -a appends a transcript to a numbered TXT file in your current folder. Research recipes are interactive, not falsely advertised as automatic one-command provider scans. Switch 03/10 and other upstream providers can still have limits or outages. Safety: Recipe 20 copies missing files into a backup directory; none of these recipes delete or overwrite vault records.

VAULT BACKUP

Copy only files missing from the destination. Existing backup files are never overwritten

LOCAL COMMAND // COPY + RUN IN RAINBOW
vault="$HOME/.local/share/deadbyte"; backup="$HOME/Documents/DEADBYTE-VAULT"; if [ -d "$vault" ]; then mkdir -p "$backup" && cp -an "$vault/." "$backup/" && printf 'BACKUP // COPIED MISSING FILES ONLY\n'; else printf 'VAULT NOT FOUND\n'; fi
