Install and preserve

DEADBYTE runs locally on Linux with Python 3. Start from the repository root with sh install.sh, then launch using deadbyte. The installer refuses to overwrite an existing installation. Private research sessions and local configuration are not bundled with this repository.

Research integrity: archive capture dates and image upload dates are not always historical event dates. Provider limitations and errors must be shown rather than disguised as missing evidence. This preview is static and has no access to your local research vault.
